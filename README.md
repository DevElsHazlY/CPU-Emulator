# CPU-Emulator
CPU Emulator هو محاكٍ لمعالج افتراضي مبني بـ Python، يهدف لتعليم هندسة الحاسب. يدعم معمارية تعليمات مخصصة (ISA)، إدارة الذاكرة، وذاكرة فيديو (VRAM). ينفذ دورة (Fetch-Decode-Execute) بدقة، مع هيكلية اختبار مدمجة. نواة تعليمية قابلة للتطوير مستقبلاً نحو دعم Assembler وواجهة رسومية متكاملة.
